## LATEST Changes

* Added a wheel animation override, `Vehicle.set_wheel_animation_override`, in which the wheels show only the values set through `Vehicle.set_wheel_steer_direction` and the new `set_wheel_pitch_angle` and `set_wheel_suspension_offset`, with matching getters, whether or not Chaos simulates the vehicle. It is meant for replays and co-simulation platforms that bring their own wheel state, Chrono's suspension say. It is visual only, and the setters raise an error while it is off. The wheel getters, `get_wheel_steer_angle` included, now raise an error for a wheel location the vehicle does not have instead of returning `0.0`.
* Vehicle wheels now roll when Chaos is not the one moving the vehicle. They used to freeze whenever physics was disabled (`set_simulate_physics(False)` with the vehicle moved through `set_transform`, replays, the Traffic Manager's hybrid physics mode) or another movement component had replaced Chaos, because the engine's `VehicleAnimationInstance` only reads wheel poses from the Chaos simulation. A new `UCarlaVehicleAnimationInstance`, now the parent class of every vehicle animation blueprint, turns each wheel in those cases by the distance it actually travels, forwards or backwards, ignoring teleports. Wheels of vehicles simulated by Chaos are unaffected, and steering is not animated in those cases. Custom vehicles need their animation blueprint reparented to `CarlaVehicleAnimationInstance` to get this; until then they behave as before.
* Optimized the DVS camera (`sensor.camera.dvs`) grayscale conversion step with integer weights and parallel rows, with bit-identical output. In a 1280x720 benchmark the conversion itself is about 8x faster in log mode and 4x in linear mode. The overall DVS frame time improves less, because event generation and the GPU readback are unchanged. Added DVS smoke tests.
* Added an agent skill library: 60 vetted CARLA procedures under `skills/`, covering setup, the Python API, UE 4.26 / 5.5 / 5.8 builds, packaging and asset imports, Scenario Runner, Leaderboard, Scenic and the native ROS 2 interface. A coding agent working inside a checkout picks them up from `AGENTS.md` in the repository root, and `Util/AgenticTools/` serves the same library over MCP (registered for the project by `.mcp.json`) for clients that also want per-skill environment checks and path configuration that persists between sessions. Documented in `Docs/agent_skills.md`.
* Hardened `Vehicle.get_wheel_steer_angle` on UE5: the angle (degrees, straight from the Chaos solver) is now returned only after checking the movement component, the requested wheel location and the solver's per-wheel output, so a vehicle with fewer wheels than the requested location returns `0.0` with a `LogCarla` warning instead of risking the solver `check()`, and vehicles with physics disabled return `0.0` silently instead of logging a warning on every call. Added the `smoke.test_vehicle_wheel_steer_angle` smoke test.
* Reworked the RGB camera look: the viewport, the spectator and every `sensor.camera.rgb` without an explicit `post_process_profile` now load the same photoreal camera profile (new cvar `carla.PostProcess.Profile`, default `Default`), and the weather no longer forces exposure on top of it. Reworked the overcast and rain sky (a continuous cloud deck from cloudiness 80 to 100) and the night sky (darker moon and stars, no dusk-coloured sky sphere at night, subtle city glow on clouds), and lighting now settles in a few seconds after a large `set_weather` jump. Street lights work in lumens (authored values below 1000 are read as kilolumens), and a light's intensity is converted only once instead of again on every day/night change. Lights are only updated when a weather change crosses sunrise or sunset: every `set_weather` used to walk all of them (about 270 ms per call on Town12), and lights that stream in later on World Partition maps now take the current day/night state. `LightManager.set_day_night_cycle(False)` is now also respected by the sky rig. `LightManager.get_all_lights()` no longer keeps lights that streamed out of a World Partition map: the client cache is rebuilt from each server snapshot instead of only growing. Fixed rain never following the spectator or the sensors (`BP_CarlaWeather` was saved with tick disabled). Added the `GoPro`, `AutomotiveHDR` and `Dashcam` camera presets, documented in `Docs/camera_postprocess_presets.md`.
