# C++ client detail

## The in-tree examples

`Examples/CMakeLists.txt` builds them when `BUILD_EXAMPLES=ON` (the default). Both link `carla-client` directly, so they need nothing beyond the build tree.

| Target | Source | What it does |
|---|---|---|
| `carla-example-client` | `Examples/CppClient/main.cpp`, `Quickstart.cpp` | prints both versions, loads a random map from `GetAvailableMaps()`, spawns a random vehicle, moves the spectator, destroys the vehicle. Arguments: none, or `HOST PORT`. |
| `carla-agent-demo` | `Examples/CppClient/AgentDemo/main.cpp` | spawns a vehicle, plans to a distant spawn point and drives there with a `BehaviorAgent`, printing throttle and steer every N steps; Ctrl-C stops it. Arguments: `HOST PORT MAP BEHAVIOR`. |

`Examples/CppClient/Standalone/` and `AgentDemo/CMakeLists.txt` are out-of-tree versions of the same idea. Their README omits the dependency wiring and hard-codes `localhost:2000`; the skill's `assets/project` replaces them.

## What the installed package holds

`cmake --install Build/<preset>/LibCarla --prefix P` writes:

| Path | Contents |
|---|---|
| `P/lib/libcarla-client.a` | the client library (~20 MB) |
| `P/include/carla/**` | LibCarla's headers |
| `P/lib/cmake/Carla/CarlaConfig.cmake` | `Carla::carla-client`, an imported static target with LibCarla's include path and C++20 |

It does not hold the vendored dependencies. `CarlaDeps.cmake` adds them from `Build/<preset>/_deps`:

| Dependency | Headers | Library |
|---|---|---|
| Boost | `boost-src/libs/*/include` | `boost-build/libs/<lib>/libboost_<lib>.a` for context, graph, random, serialization, thread, date_time, container, atomic, chrono, filesystem |
| rpclib | `rpclib-src/include` | `rpclib-build/librpc.a` |
| Recast/Detour | `recastnavigation-src/{Recast,Detour,DetourCrowd}/Include` | the three matching `.a` files |
| libpng, zlib | `libpng-src`, `libpng-build`, `zlib-src`, `zlib-build` | `libpng16.a`, `libz.a` |

plus the defines `LIBCARLA_IMAGE_SUPPORT_PNG=1`, `RPCLIB_LINUX`, `RPCLIB_MSGPACK=clmdep_msgpack` and Boost's static-link defines. The list mirrors the link line CMake generates for `carla-example-client` in `Build/<preset>/build.ninja`; if a future build adds a dependency, compare against it.

## API entry points

The [C++ tutorial](../../../../Docs/tuto_cpp.md) covers batch commands (`carla::rpc::Command`, `Client::ApplyBatchSync`), snapshots (`World::WaitForTick`), the recorder (`Client::StartRecorder`, `ReplayFile`) and the C++ navigation agents (`carla/agents/navigation/BasicAgent.h`, `BehaviorAgent`, `ConstantVelocityAgent`). The Doxygen reference is generated by `doxygen` from the repository root ([ref_cpp.md](../../../../Docs/ref_cpp.md)).

## Measured on ue58-dev ccc52d24d

- In-tree build of both examples after a fresh `carla-unreal-editor` build: 12 s.
- `carla-example-client localhost 4000` against a game-mode server: loaded Town11, spawned and destroyed `vehicle.ue4.ford.mustang`, exit 0.
- `carla-agent-demo localhost 4000 Town10HD_Opt normal`: reached the destination after 29692 steps.
- The template project against a scratch install: built and printed `map Carla/Maps/Town10HD_Opt, 155 spawn points, 24 actors`; against a closed port it prints `Connection refused` and exits 1.
- Without `CarlaDeps.cmake`, `Examples/CppClient/Standalone` fails to compile (`'rpc/msgpack.hpp' file not found`, plus the system Boost's `no member named 'result_of' in namespace 'std'`).
