# C++ reference

CARLA's C++ code is documented with [Doxygen](https://www.doxygen.nl/), from the comments in the headers.

The copy hosted at <http://carla.org/Doxygen/html/index.html> is regenerated by the `UE5-Doxygen` GitHub Actions workflow, run manually on `ue58-dev`. To browse a local branch, generate it with the steps below.

---
## Generate the documentation

The hosted copy is generated with Doxygen **1.18.0**. Older versions also work, but the page looks different and loads more JavaScript. Ubuntu's `apt` package is older (1.9.8 on 24.04); to match the hosted copy, use the release binary from [doxygen.nl](https://www.doxygen.nl/download.html):

```sh
curl -fsSLO https://github.com/doxygen/doxygen/releases/download/Release_1_18_0/doxygen-1.18.0.linux.bin.tar.gz
tar -xzf doxygen-1.18.0.linux.bin.tar.gz
export PATH="$PWD/doxygen-1.18.0/bin:$PATH"
```

From the repository root, where the `Doxyfile` lives:

```sh
doxygen
```

The result is written to `Doxygen/html/`. Open `Doxygen/html/index.html` in a browser.

The main page is `Util/CppReference/mainpage.md`: a short index of the LibCarla namespaces and the Carla plugin's entry classes. When a module is added or renamed, update its row there.

---
## What is covered

| Path | Contents |
| --- | --- |
| `LibCarla/source` | The client and server library: the C++ client API, the RPC types, the geometry, the sensor serialization, the Traffic Manager and the navigation agents. |
| `Unreal/CarlaUnreal/Plugins/Carla/Source` | The Carla plugin: the actors, the sensors and the server side of the simulation. |
| `Unreal/CarlaUnreal/Source` | The Unreal project itself. |

For using the C++ client rather than reading its internals, start with the [C++ tutorial](tuto_cpp.md).
