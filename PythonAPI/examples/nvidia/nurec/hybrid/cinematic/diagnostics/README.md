# Shot-specific diagnostic scripts

Archived source used to prepare and validate the sh031 pedestrian contact fix.
These scripts retain their original shot paths and Blender/workspace assumptions;
edit those paths before using another checkout. Run Blender scripts only in a
scratch Blender process: receiver export clears the current scene. The source
pedestrian asset, caches, receiver samples and rendered data are external inputs
and are not included in Git. Reusable contact math lives in the parent directory.
